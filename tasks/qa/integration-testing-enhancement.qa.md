## 🧪 테스트 시나리오

### 1. Maven 프록시 통합 테스트
1. **SNAPSHOT 버전 처리**
   - SNAPSHOT 패키지 요청 및 정기적 업데이트 확인
   - 버전 메타데이터 병합 검증
2. **체크섬 검증**
   - .sha1, .md5 엔드포인트 정상 응답 확인
   - 체크섬 값 정확성 검증
3. **디렉토리 브라우징**
   - 브라우징 토글 기능 동작 확인
   - HTML 렌더링 vs JSON 응답 전환

### 2. YUM 프록시 통합 테스트
1. **repodata 신선도 검사**
   - repodata 자동 업데이트 확인
   - 메타데이터 캐시 관리 검증
2. **gzip/pgp 헤더 처리**
   - 압축된 패키지 핸들링
   - GPG 서명 검증 처리
3. **Range 요청 지원**
   - 부분 다운로드 요청 처리
   - 대용량 패키지 효율적 전송
4. **미러 페일오버**
   - 주 미러 실패 시 자동 전환
   - 백업 미러 연결성 확인

### 3. APK 프록시 통합 테스트
1. **서명 검증**
   - APK 패키지 서명 검증 실패 경로 테스트
   - 유효하지 않은 서명 거부 확인
2. **미러 자동 전환**
   - 주 저장소 접근 불가 시 미러 전환
   - 지역별 미러 우선순위 적용
3. **APKINDEX 압축 처리**
   - 압축된 인덱스 파일 처리
   - 패키지 메타데이터 파싱
4. **패키지 다운로드**
   - APK 파일 무결성 검증
   - 다운로드 완료 확인

### 4. 공통 테스트 패턴 검증
1. **캐시 시나리오**
   - 캐시 HIT: < 10ms 응답 시간
   - 캐시 MISS: < 5초 응답 시간
   - 캐시 적중률 > 70% 달성
2. **에러 처리 및 복구**
   - 네트워크 오류 시 재시도 로직
   - 타임아웃 처리 및 적절한 에러 메시지
3. **성능 검증**
   - 동시 요청 100개 이상 처리
   - 메모리 사용량 안정성
   - CPU 사용률 최적화
