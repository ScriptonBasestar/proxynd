# 🚀 ProxyND Features

ProxyND는 기업 환경에서 패키지 다운로드 속도 향상과 대역폭 절약을 위한 고성능 패키지 매니저 프록시/미러 서버입니다.

---

## 📦 패키지 레지스트리 지원

### 멀티 레지스트리 프록시
- **APT 패키지**: Ubuntu, Debian 등 데비안 계열 리눅스 패키지 관리
- **YUM/DNF 패키지**: CentOS, RHEL, Rocky Linux 등 RedHat 계열 리눅스 패키지 관리
- **NPM 패키지**: Node.js 패키지 레지스트리 (npmjs, yarn, taobao 미러 지원)  
- **Python PyPI**: Python 패키지 인덱스 (PyPI, douban, aliyun 미러 지원)
- **Docker 레지스트리**: Docker Hub, GCR, Quay 등 컨테이너 이미지 저장소

### 통합 프록시 API
- 단일 서버에서 여러 패키지 매니저 동시 지원
- RESTful API: `/proxy/{type}/{path}` 형태로 통일된 인터페이스 제공
- 원본 패키지 경로 구조 그대로 유지하여 클라이언트 설정 최소화

---

## ⚡ 캐싱 및 성능

### 지능형 캐시 시스템
- **캐시 자동 관리**: 첫 요청 시 업스트림에서 다운로드 후 로컬 캐시 저장
- **Hit/Miss 판단**: 요청별 캐시 상태 실시간 확인 및 로깅
- **TTL 기반 만료**: 패키지 유형별 차별화된 캐시 만료 정책

### 다중 스토리지 백엔드
- **로컬 파일시스템**: 빠른 접근을 위한 로컬 디스크 캐시
- **Amazon S3**: 확장 가능한 클라우드 스토리지 (MinIO 등 S3 호환 스토리지 지원)
- **LRU 정책**: 디스크 공간 부족 시 자동으로 오래된 캐시 정리

### 성능 최적화
- **멀티아키텍처 지원**: AMD64, ARM64 플랫폼 최적화
- **압축 지원**: gzip 압축으로 네트워크 대역폭 절약
- **병렬 처리**: 다중 요청 동시 처리로 응답 시간 단축

## 🔒 보안 및 접근 제어

### 인증 시스템
- **BasicAuth**: 사용자명/패스워드 기반 인증
- **사용자별 권한**: 읽기/쓰기/삭제/관리자 권한 세분화
- **프록시별 접근 제어**: 사용자가 접근 가능한 패키지 레지스트리 제한

### 네트워크 보안
- **IP 화이트리스트**: CIDR 표기법으로 허용 네트워크 대역 설정
- **패키지 필터링**: 허용/차단 패키지 목록으로 보안 위험 패키지 차단
- **TLS/HTTPS 지원**: 암호화된 통신으로 데이터 보호

### 패키지 검증
- **SHA256 해시 검증**: 다운로드된 패키지 무결성 자동 검증
- **검증 실패 처리**: 위조/변조된 패키지 자동 차단 및 알림
- **GPG 서명 검증**: APT 패키지 GPG 키 검증 지원

## 📊 모니터링 및 운영

### 메트릭 및 모니터링
- **Prometheus 메트릭**: `/metrics` 엔드포인트로 운영 지표 수집
  - 요청 수, 응답 시간, 캐시 적중률
  - 인증 성공/실패, 에러율
  - 시스템 리소스 사용량
- **헬스체크 API**: `/healthz` 엔드포인트로 서비스 상태 모니터링

### 로깅 시스템
- **구조화된 로깅**: JSON 형태로 구조화된 로그 출력
- **액세스 로그**: 모든 요청/응답 기록으로 감사 추적 가능
- **로그 레벨 제어**: DEBUG, INFO, WARN, ERROR 등 세분화된 로그 레벨
- **로그 순환**: 파일 크기 및 보관 기간 기반 자동 로그 순환

### 알림 시스템
- **다중 채널 알림**: 로그, 웹훅, 이메일을 통한 장애 알림
- **임계값 기반 알림**: 디스크 사용량, 메모리 사용량 등 임계값 초과 시 알림
- **패키지 검증 실패 알림**: 보안 위험 패키지 감지 시 즉시 알림

## 🚀 최근 완료된 기능

### APK 프록시 지원 (Alpine Linux)
- Alpine Linux 패키지 관리자 완벽 지원
- APKINDEX.tar.gz 파일 처리 및 캐싱
- APK 서명 검증 로직 구현
- Alpine 버전별 미러 자동 선택

### ProxyND CLI 도구 (proxyndctl)
- 캐시 관리 명령어 (list, clear, size)
- 설정 검증 및 조회 기능
- 서버 상태 모니터링
- 사용자 관리 기능
- 프록시 연결성 테스트
- 자동완성 스크립트 지원

### Webhook 알림 시스템
- Slack, Discord, Teams 통합
- 커스터마이징 가능한 이벤트 필터링
- 재시도 메커니즘 및 rate limiting
- 다양한 인증 방식 지원 (Bearer, HMAC)

### 패키지별 TTL 고도화
- 패키지 타입별 차별화된 TTL 설정
- 패턴 기반 TTL 오버라이드
- 캐시 헤더 기반 동적 TTL 계산
- Stale-while-revalidate 지원

### OAuth2 인증 시스템
- GitHub, GitLab, Google OAuth2 프로바이더 지원
- JWT 토큰 발급 및 자동 갱신
- 기존 BasicAuth와 완벽한 통합
- 사용자 권한 자동 동기화
