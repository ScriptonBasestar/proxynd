# ProxyND 오픈소스 철학

## 🌍 우리의 오픈소스 비전

ProxyND는 **GitLab 모델**을 따라 모든 코드를 공개합니다. 엔터프라이즈 기능을 포함한 전체 소스코드가 AGPL-3.0 라이센스로 공개됩니다.

## 💡 왜 모든 것을 공개하는가?

### 1. **투명성 = 신뢰**
```
"Security through obscurity is not security"
```
- 고객은 자신이 사용하는 코드를 검증할 권리가 있습니다
- 숨겨진 백도어나 취약점이 없음을 증명합니다
- 커뮤니티가 보안 문제를 발견하고 수정할 수 있습니다

### 2. **협업의 힘**
- 대기업들도 개선사항을 기여할 수 있습니다
- 버그 수정이 더 빠르게 이루어집니다
- 혁신이 커뮤니티 전체에 도움이 됩니다

### 3. **벤더 종속성 해소**
- 고객이 필요시 자체적으로 유지보수 가능
- 회사가 없어져도 프로젝트는 계속됩니다
- 진정한 오픈소스 생태계 구축

## 🏢 비즈니스 모델

### "코드는 무료, 시간은 유료"

#### 무료로 제공하는 것:
- ✅ 전체 소스코드
- ✅ 문서와 가이드
- ✅ 커뮤니티 지원
- ✅ 버그 수정

#### 유료로 제공하는 것:
- 💰 엔터프라이즈 기능 **활성화** 라이센스
- 💰 전문가 지원 (SLA)
- 💰 컨설팅 및 커스터마이징
- 💰 교육 및 인증
- 💰 법적 보증 및 배상책임

## 🔐 라이센스 시스템

### 기술적 구현
```go
// 모든 엔터프라이즈 기능은 코드에 포함되지만
// 라이센스가 있어야 활성화됩니다

if license.HasFeature("advanced_caching") {
    // 고급 캐싱 로직 실행
} else {
    // 기본 캐싱 사용
}
```

### 라이센스 철학
1. **정직한 사용**: 라이센스 우회는 가능하지만 불법입니다
2. **가치 제공**: 지원과 보증이 진짜 가치입니다
3. **상호 신뢰**: 고객을 신뢰하면 고객도 우리를 신뢰합니다

## 💬 자주 묻는 질문

**Q: 누군가 코드를 복사해서 경쟁 제품을 만들면?**
A: AGPL은 그들도 코드를 공개해야 합니다. 우리의 경쟁력은 코드가 아닌 전문성과 서비스입니다.

**Q: 대기업이 라이센스 없이 사용하면?**
A: 법적 리스크를 감수하는 것입니다. 대부분의 기업은 적법한 사용을 선호합니다.

**Q: 왜 MIT나 Apache가 아닌 AGPL인가?**
A: 클라우드 시대에 맞는 라이센스입니다. 서비스로 제공할 때도 소스 공개를 요구합니다.

## 📝 결론

> "오픈소스는 개발 방법론이 아니라 철학입니다"

우리는 코드를 판매하지 않습니다. 
우리는 **신뢰**, **전문성**, **책임**을 판매합니다.

모든 코드가 공개되어 있지만, 고객이 우리를 선택하는 이유는 명확합니다:
- 가장 빠른 문제 해결
- 가장 안정적인 운영
- 가장 신뢰할 수 있는 파트너
