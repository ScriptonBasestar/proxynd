### 1. 플레이스홀더 설명

| `{예상_기간}` | 작업 소요 기간 | "3-5일", "1주" |

### 2. Phase별 특화 내용

#### Phase 1: 핵심 기반 구축
- **중점**: 의존성 관리, 에러 처리
- **주요 패턴**: DI 컨테이너, Factory, Strategy
- **검증**: 단위 테스트 중심

#### Phase 2: 코드 품질 개선
- **중점**: 중복 제거, 테스트 커버리지
- **주요 패턴**: Template Method, Extract Method
- **검증**: 커버리지 측정, 정적 분석

#### Phase 3: 인터페이스 표준화
- **중점**: API 일관성, 문서화
- **주요 패턴**: Facade, Adapter
- **검증**: API 테스트, 문서 생성

#### Phase 4: 성능 최적화
- **중점**: 동시성, 리소스 관리
- **주요 패턴**: Object Pool, Async/Await
- **검증**: 부하 테스트, 프로파일링

### 3. 언어별 조정사항

#### 정적 타입 언어
- 타입 시스템 활용한 리팩토링 강조
- 컴파일 타임 검증 활용
- 인터페이스 기반 설계

#### 동적 타입 언어
- 런타임 검증 추가
- 더 많은 테스트 케이스
- 타입 힌트/문서화 강조

### 4. 프로젝트 규모별 조정

#### 대규모 (100K+ LOC)
- 더 작은 단계로 세분화
- 병렬 작업 가능 영역 식별
- 단계적 롤아웃 계획

#### 중규모 (10K-100K LOC)
- 표준 템플릿 그대로 사용
- 2-3주 단위 스프린트
- 팀 전체 참여

#### 소규모 (<10K LOC)
- Phase 통합 가능
- 빠른 반복
- 1-2명이 전담
