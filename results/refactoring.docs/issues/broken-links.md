## ⚠️ 주의가 필요한 링크들

### 1. 프로젝트 루트 참조
일부 문서에서 프로젝트 루트의 파일들을 참조하는 링크들:
- `Makefile` 참조
- `docker-compose.yml` 참조
- `scripts/` 디렉토리 참조

### 2. 외부 링크
GitHub, 공식 문서 등 외부 링크들은 별도 검증 필요:
- Maven Central 관련 링크
- NPM Registry 관련 링크
- Docker Hub 관련 링크

### 3. 이미지 및 자산 참조
문서 내 이미지나 기타 자산 파일 참조가 있다면 경로 확인 필요

## 🛠️ 권장 조치

### 즉시 조치
1. **링크 검증 도구 설치** (선택사항)
   ```bash
   npm install -g markdown-link-check
   ```

2. **자동 링크 검증 실행** (선택사항)
   ```bash
   find docs/ -name "*.md" -exec markdown-link-check {} \;
   ```
