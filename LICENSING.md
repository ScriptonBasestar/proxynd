# ProxyND Licensing Guide

## Dual Licensing Model

ProxyND is available under two different licenses:

### 1. Open Source License (AGPL-3.0)
- **Free** for all uses
- Source code modifications must be shared
- Network use (SaaS) requires source disclosure
- Perfect for open source projects

### 2. Commercial License
- **Paid** license for enterprises
- Keep modifications private
- No source disclosure required
- Includes support and enterprise features

## Which License Do I Need?

### Use AGPL License if:
- ✅ You're using ProxyND internally and don't mind sharing modifications
- ✅ You're building an open source project
- ✅ You're evaluating ProxyND
- ✅ You're using it for personal/educational purposes

### Need Commercial License if:
- ❌ You want to keep modifications private
- ❌ You're offering ProxyND as a SaaS without source disclosure
- ❌ You need enterprise support and SLA
- ❌ You're embedding ProxyND in a proprietary product

## Common Scenarios

### Scenario 1: Internal Corporate Use
- **AGPL**: Yes, if you share any modifications publicly
- **Commercial**: Recommended for proprietary modifications

### Scenario 2: SaaS Provider
- **AGPL**: Must provide source code to users
- **Commercial**: Can keep source private, better for business

### Scenario 3: Consulting/Integration
- **AGPL**: Client must comply with AGPL
- **Commercial**: Cleaner for client deliverables
